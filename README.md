# E-Cell SVCE Website

The official website for the Entrepreneurship Cell (E-Cell) at Sri Venkateswara College of Engineering (SVCE).

## Features
- Modern, responsive design with upgraded typography system (Space Grotesk & Plus Jakarta Sans)
- Interactive particle background system
- Comprehensive Ecosystem, Programs, Events, Team, Blog, and Alumni hubs
- Responsive navigation with animated menu interactions

## Tech Stack
- Next.js
- React & TypeScript
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```
